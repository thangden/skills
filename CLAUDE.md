# CLAUDE.md

This repository ships public Claude Code skills. The current set is small — `aos` (Agentic OS Setup) under `skills/setup/`.

## Skill organization

Skills live at `skills/<bucket>/<name>/SKILL.md`. Buckets in use:

- `setup/` — bootstrap / configuration skills (e.g. aos)

Future buckets follow the convention: `engineering/`, `productivity/`, `misc/` for shipped skills; `personal/`, `in-progress/`, `deprecated/` for skills not ready to ship.

Every shipped skill must have:

- An entry in `.claude-plugin/plugin.json`
- A link in the top-level `README.md`
- Its own `SKILL.md` with a frontmatter `name` and `description` that lists trigger conventions

Skills in `personal/`, `in-progress/`, `deprecated/` must not appear in either `plugin.json` or `README.md`.

## Architecture decisions

Each shipped skill carries its own `docs/adr/` directory for hard-to-reverse decisions. Read the relevant ADRs before changing behaviour.

## Terminology

Repo-wide terminology lives in the top-level [CONTEXT.md](CONTEXT.md). Skill-specific terminology lives in the skill's own `CONTEXT.md`.

## Operating constraints

- Pull requests should not touch unrelated skills.
- No personal/team identifying content commits to public — keep it in your local dogfood workspace under `.claude/` (git-ignored).
- Hooks generated by skills warn rather than block, with the single exception of schema validation (per the relevant skill's ADR).
