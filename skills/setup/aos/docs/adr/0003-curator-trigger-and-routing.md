# 0003 — Curator triggers implicitly and explicitly; confidence drives when to ask

aos v1 Curator was invoked only via `@memory-curator` or `/curate`, and always asked the user to classify before saving. Field tests showed the majority of Non-Tech users don't reliably remember skill names; explicit-only triggering produced near-zero usage. Meanwhile, Anthropic's own auto-memory pattern has Claude proactively decide what to save without a user command. v2 needed a model that captures memory-worthy moments without forcing the user to remember a command, while keeping the user in control of routing.

Curator now triggers in two ways. Implicitly, Claude monitors for memory-worthy signals — explicit cues like `ghi nhớ`, `remember`, `from now on`, `đừng X anymore`, plus content-shape signals (a durable fact, a preference, a workflow rule, an external pointer) — and invokes Curator inline. Explicitly, the user can still type `@curator` or `/curate <info>` to force routing.

Routing itself is confidence-driven. Curator infers `scope` and `type` from context and scores its confidence. At `confidence >= 0.8` it auto-saves and announces the destination, scope, type, and a one-line override path. Below `0.8` it asks exactly one targeted question — the dimension it's least sure about, usually scope or type, never both — and saves on the answer. Every save announces its path; the user can reply `no` or `override scope=personal` to relocate. Auto-saves are logged to the day's episodic Entry so reversals are traceable.

Explicit-only triggering already failed in v1. Implicit-only routing without confidence gating would either ask too often (annoy) or save silently (lose control). Confidence gating exits that binary: high-signal saves move fast, low-signal saves ask once. Announcing every destination keeps the system legible — the user always knows where their words went and can fix mistakes immediately.

The `0.8` threshold is a calibration knob, not an architectural commitment. Expect to retune after a few weeks of real use. Curator must emit a structured announcement (`saved: <path>` plus `scope`, `type`, `confidence`) so downstream tools — Janitor today, Promoter later — can parse and audit. Implicit triggering carries a false-positive risk during casual conversation; the mitigation is confidence gating plus episodic logging plus one-word rollback. If false positives prove intolerable, falling back to explicit-only is a `CLAUDE.md` flag away, not a re-architecture.
